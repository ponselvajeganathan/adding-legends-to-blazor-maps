# Adding Legends to Blazor Maps

This sample demonstrates how to add and customize legends in **Syncfusion Blazor Maps** within a **Blazor WebAssembly** application. The project focuses on configuring legends to improve data visualization by showing map-related information in a clear and user‑friendly way. It illustrates how different legend settings affect the appearance and behavior of maps when rendering geographical data.

The sample includes practical implementations for aligning legends, changing legend modes, configuring legend positions, customizing legend icons, and excluding specific items from the legend display. These configurations help developers control how map data is presented to end users.

## Project Overview

The application is built using Blazor WebAssembly and leverages the Syncfusion Blazor Maps component. It serves as a reference implementation for developers who want to understand legend configuration options available in Syncfusion Maps and apply them effectively in real-world applications.

## Key Features

- Add legends to Blazor Maps
- Align legends based on layout requirements
- Switch between different legend modes
- Control legend position and visibility
- Customize legend icons
- Skip specific shapes or items in the legend

## Prerequisites

- Visual Studio 2022
- .NET SDK compatible with Blazor WebAssembly
- Basic knowledge of Blazor and component-based UI development

## How to Run the Project

1. Clone or download this repository to your local machine.
2. Open the solution file using **Visual Studio 2022**.
3. Restore the required NuGet packages by rebuilding the solution.
4. Run the project to view the Blazor Maps legend examples in the browser.

## Usage

Use this sample as a reference to understand legend-related APIs in Syncfusion Blazor Maps. You can adapt the demonstrated configurations to suit your own map-based applications and customize legends as needed.
