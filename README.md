# Adding Legends to Blazor Maps

## Overview

This sample demonstrates legend customization using the Syncfusion [Blazor Maps](https://www.syncfusion.com/blazor-components/blazor-map) component in a hosted Blazor WebAssembly application. The implementation focuses on configuring map legends to improve data interpretation and geographic visualization. The sample illustrates how legends can be aligned, repositioned, displayed in different modes, customized with alternative icons, and selectively configured to exclude specific legend items. These capabilities help users better understand shape color mappings and geographic data rendered within the map.

## Key Features

- Demonstrates legend rendering within the Syncfusion Maps component.
- Shows how to configure legend alignment for better layout presentation.
- Demonstrates changing legend display modes for different visualization requirements.
- Shows how to position legends within the map interface.
- Demonstrates custom legend icon configuration.
- Illustrates how specific items can be excluded from legend display.
- Demonstrates legend integration with map shape rendering and color mapping.
- Uses map legend settings to improve interpretation of geographic data.

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `AddingLegendInMap.sln`

3. Restore NuGet packages.
4. Set the startup project t
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root or startup project directory.

```bash
dotnet restore
dotnet run
```
